How does scheduled bus service change across the week at local transit anchors? Explore eight starting points, then inspect the routes behind the numbers.

Metro schedule snapshot · Fall 2026 · Bus service only

Loading the published schedule snapshot…

Make schedules easier to compare.

A resident or community advocate may need to understand how an anchor’s service changes on weekends. The interface keeps the same location and time window while switching the service day.

Start with the service calendar.

A Python pipeline scans 1,107,809 stop-time rows, applies calendar exceptions, excludes no-pickup stops, and counts a trip only once per anchor. Route-direction gaps use consecutive departures within the selected window.

Test access, beyond frequency.

This prototype can identify schedule questions for follow-up. A next iteration would validate anchor choices with residents, add destination-based travel times, and test the interface with keyboard and screen-reader users. No resident research is claimed here.

Scope & evidence

These are named stop groups, not citywide totals or an equity ranking. Group sizes differ. Scheduled departures do not measure actual reliability, ridership, accessibility, or door-to-door travel time. Gaps across multiple routes are not estimated waits. Service dates are fixed so this analysis remains reproducible.
