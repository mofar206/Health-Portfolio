01

A transparent input

The neighborhood explorer uses a local scenario dataset. Selecting a ZIP code updates the same record across every metric.

02

An explicit comparison

The chart compares the selected uninsured share with five named scenarios. These are sample values, not a measured county benchmark.

03

A separate public source

CDC PLACES provides county health indicators. Supplemental Census requests explicitly specify King County, validate percentages, and report unavailable sources.

Data provenance & limitations +

ZIP codes are not census tracts, and neighborhood labels may span boundaries. Clinic counts in this prototype have not been verified for service type, capacity, language access, or insurance acceptance. CDC uninsured prevalence covers adults aged 18 to 64. The separate Census uninsured measure covers the civilian noninstitutionalized population; these denominators should not be combined. No county-wide impact or demographic-group disparity is inferred from these sample records.
